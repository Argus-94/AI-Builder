AI Builder — аудит цепочек сборки APK
Дата: 2026-09-27
База: AIBuilder-Expo-v116 → правки в v117 (1.6.97)

================================================================================
КАК МОДЕЛИРОВАЛАСЬ РАБОТА
================================================================================
По коду прослеживаются сценарии пользователя → ветка termux-agent /
agent-engine → shell/Gradle → критерий успеха (AIB_DETERMINISTIC_APK /
verifyApkOnDevice / TERMUX_DONE gates).

Сценарий A: «Создай Hello World» / create from scratch
  useLLM: Termux ON + isStrongCreateAppTask → runTermuxAgentTask
  → isCreateAppTask → runCreateAppWithRetry
  → ensureAndroidToolchain → runDeterministicCreateApp
  → buildDeterministicCreateAppScript (shell) → gradlew assembleDebug
  → AIB_DETERMINISTIC_APK=… → verifyApkOnDevice → ответ пользователю
  При провале → LLM-агент / final engine runCreateAppWithRetry

Сценарий B: «Собери APK из исходников / zip»
  isApkBuildTask → autonomous prepare (unzip/find project) →
  assemble offline → online → collect APK → recovery LLM

Сценарий C: LLM TERMUX_DONE с путём к APK
  structural gates → verifyApkOnDevice (файл + размер ≥ 8KB)

   тянет Maven/AndroidX, ломает офлайн/слабый сеть.
   FIX: dependencies {} пустой, только framework Activity.

2. [КРИТ] Не было gradle.properties

   FIX: добавлен gradle.properties.

   Без pluginManagement / dependencyResolutionManagement резолв

   FIX: PREFER_SETTINGS + google/mavenCentral/gradlePluginPortal.

4. [ВЫСОК] compileSdk=34 жёстко, хотя на устройстве может не быть
   platform android-34.
   FIX: COMPILE_SDK из установленных platforms, sed в app/build.gradle.

   FIX: проверка android-*/android.jar; toolchain ok требует
   !sdk_platforms=MISSING.

8. [СРЕД] Offline assemble timeout 180s
   Холодный Gradle/AGP download не успевал.
   FIX: 600_000 ms для offline assemble.

9. [СРЕД] Детерминированный APK без проверки размера в shell
   FIX: после find APK — wc -c, < 8192 → ERROR.

10. [НИЗ] (уже было закрыто ранее) ложный TERMUX_DONE без файла
    verifyApkOnDevice + structural gates — OK.
