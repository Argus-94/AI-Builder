# Operation 0.3 — Compilation Baseline

## Purpose

This operation creates a read-only baseline of the compilation-related configuration present in the source archive received from operation 0.2.

**No project compilation setting is changed by this operation.**

## Source

- Base archive: `AIBuilder-Expo-v1_3_374-v2.zip`
- Application version: `1.3.374`
- Operation: `0.3`

## Current Android project state

The source archive does **not** contain a generated `android/` directory. Android native files are generated by Expo prebuild/config plugins.

Therefore this baseline records both:

1. the current root/source configuration;
2. the source files/plugins that can generate or modify Android compilation configuration.

The generated Android configuration itself is **not present** and must not be invented or substituted with another configuration.

## Compilation-related source generators

The repository contains source-level generators/templates with Android compilation values or generation logic. They are part of the baseline and are not changed in operation 0.3.

Notably:

- `lib/project-generator.ts` contains generator defaults/templates for Android projects, including compile/target/min SDK and Java/Kotlin compatibility.
- `plugins/withEnsureBuildConfig.js` modifies generated `android/app/build.gradle`.
- `plugins/withFixGradleProperties.js` modifies generated Gradle properties/settings.
- `app.config.ts` controls the order in which these Expo config plugins execute.

The presence of a value in a generator/template is **not treated as proof of the current generated Android value** because `android/` is absent from this archive.

## Guard rule established by this baseline

Until a later operation explicitly requires a change and passes the compilation-settings guard:

- do not change `package.json` package-manager configuration;
- do not change `pnpm-lock.yaml`;
- do not change `app.config.ts` Android/build configuration;
- do not change root `gradle.properties`;
- do not change EAS build profiles;
- do not change Android/Gradle/Kotlin/Java/SDK/NDK settings;
- do not replace the Gradle wrapper or pin another Gradle version;
- do not generate a substitute `android/` configuration merely to make a test pass.
